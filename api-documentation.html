API Reference

School Management System REST API. All endpoints accept application/x-www-form-urlencoded and return JSON.

Base URL /api/index.php
Auth Session based
Format JSON
POST Add / Update Class

Create a new class or update an existing one. Duplicate class names are rejected. Pass id to update; omit it (or send id=) to insert.

Method
POST
URI
/api/index.php
Content-Type
application/x-www-form-urlencoded
Auth
Session required
Request Parameters
Parameter Type Required Description
action string required Must be add_class
class_name string required Name of the class. Must be unique across all classes.
id integer conditional Class ID for update. Omit or leave empty to create a new record.
Example Request
POST body — Add
action=add_class&class_name=10th+Standard&id=
POST body — Update (id=3)
action=add_class&class_name=10th+Standard&id=3
Success Response
200 OK — Created
{ "success": true, "message": "Class added successfully" }
200 OK — Updated
{ "success": true, "message": "Class updated successfully" }
Error Responses
Duplicate name
{ "success": false, "message": "Class name already exists!" }
DB error
{ "success": false, "message": "Error while adding class!" }

POST Add / Update Student

Enroll a new student or update an existing student record. Pass id to update.

Method
POST
URI
/api/index.php
Auth
Session required
Status
Planned
Request Parameters
ParameterTypeRequiredDescription
action string required Must be add_student
first_name string required Student's first name.
last_name string required Student's last name.
class_id integer required ID of the class to enroll the student in.
roll_no string optional Roll number within the class.
id integer conditional Student ID — provide to update an existing record.
Success Response
200 OK
{ "success": true, "message": "Student added successfully" }
